# Campaign copy
A separate copy of the Colosseum, builders and phone page, for the campaign game. It is free to change its rules and add features.
The old pages in the folder above are not touched by anything built here.
- Own saved data: ns.js puts "campaign:" in front of every saved name in the browser, so characters, encounters and modules here never mix with the old ones.
- Open it at .../melee-combat-game/campaign/ (index.html there is the menu). Phones join through the phone page in this same folder.
- Has the magic weapons (see NOTES.md, "Magic items").
