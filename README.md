# Melee and Wizard in the browser

An unofficial fan project for playing The Fantasy Trip (Melee and Wizard) in a web browser: a character builder, solo arenas,
a two-player duel, and the Colosseum (up to four players, or you against the computer, with phones joining a shared table).

Play it: https://zaddiq.github.io/melee-combat-game/

You need the rules to play. The Fantasy Trip: Melee is a free download from Warehouse 23, the publisher's store; buy the books there
to support the authors.
